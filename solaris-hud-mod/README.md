# Solaris HUD

Modulo cliente obligatorio para instancias Solaris. Esta carpeta es el punto de partida del mod real dentro de Minecraft.

Objetivo BETA: FPS, CPS, Keystrokes, Ping, Coordenadas, Armadura, Sprint, Zoom y Durabilidad; editor HUD con Right Shift; tema amarillo/azul.

IMPORTANTE: este repositorio todavia no incluye un JAR compilado. No se coloca un archivo falso. El launcher marca el HUD como configurado pero no instalado hasta que exista `solaris-hud-*.jar` en la carpeta `mods` de la instancia.
