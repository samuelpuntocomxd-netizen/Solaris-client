# Reportar un problema de seguridad

No publiques vulnerabilidades, tokens, datos personales ni claves API en issues públicos.

Hasta que el proyecto tenga un canal privado de seguridad, contacta directamente al mantenedor del repositorio que aloje tu copia de Solaris Client. Incluye los pasos mínimos para reproducir el problema y evita adjuntar credenciales reales.

Nunca envíes tu contraseña de Microsoft a los mantenedores. El inicio de sesión debe realizarse en la ventana oficial de autenticación.
