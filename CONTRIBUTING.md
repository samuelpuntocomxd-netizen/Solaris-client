# Cómo contribuir

¡Gracias por querer mejorar Solaris Client!

1. Haz un fork del repositorio y crea una rama con un nombre descriptivo.
2. Mantén los cambios pequeños y enfocados.
3. No incluyas credenciales, tokens, claves API ni archivos de Minecraft.
4. Ejecuta `npm run check` antes de enviar el cambio.
5. Explica qué problema resuelve tu propuesta y cómo probarla.

Para cambios visuales, procura respetar el modo ligero y las preferencias de movimiento reducido. Para cambios en Electron, conserva `contextIsolation`, `nodeIntegration: false` y el sandbox.

Las contribuciones se publican bajo la licencia MIT del proyecto, salvo que se indique expresamente otra cosa.
